# Cinema iQ for iPhone — initial implementation

Scope reservation: ios/ only, plus an optional manual simulator-check workflow. Native SwiftUI app, Dawwirli browse/search/details/seasons, AVPlayer playback, isolated local saved/progress/history, and Firebase email account/shared Android-compatible sync. No Android edits, version bump, APK/IPA export or public release. Work in progress; Xcode/device checks pending. Firebase requires a separately registered iOS app configuration, not the Android google-services.json.
