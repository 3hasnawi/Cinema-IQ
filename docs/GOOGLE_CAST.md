# Google Cast status

Google Cast was removed from the iPhone/iPad and Android mobile players at the user's request on 15 November 2026. The sender UI, discovery registration, connection lifecycle, Cast-only policies/tests and Google Cast SDK dependencies are removed.

See [the removal record](MOBILE-CAST-REMOVAL.md) for scope and verification. Earlier implementation details remain available in Git history. Native Apple AirPlay and the internal quality, audio and subtitle controls continue to use their existing paths.
