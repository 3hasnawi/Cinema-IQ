# Mobile Google Cast

Work in progress for Android phones and iPhone. Apple TV and Android TV playback stay unchanged.

Planned files: mobile player, Android Cast adapter/options/manifest/dependencies, iPhone Cast adapter/player/app bootstrap, iOS project SDK setup, protocol tests and this document.

The default media receiver pulls media directly over the receiver's network. No proxy, credential forwarding or protection bypass is added. Only receiver-compatible media and WebVTT subtitle URLs can be sent. Real-device verification remains required.
