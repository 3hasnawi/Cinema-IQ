# الرئيسية 0.7

HomeScreen.kt يحتوي HomeScreen وHeroBackdrop وHeroContentInfo وHeroActionButtons وContentRailRow وLandscapeMediaCard. CinemaApp.kt يوجّه الرئيسية إليه، وتبقى الأقسام والبحث والإعدادات والرجوع كما هي.

- الخلفية 75% من مساحة المحتوى، والجزء الأول من القائمة 60% لبدء ظهور الصفوف على الشاشة. القائمة الرأسية تسمح برؤية الصفوف الباقية.
- Coil crossfade وCrossfade للصور مع تدرج رأسي Transparent→#CC000000→#000000 وتدرج أفقي معكوس في RTL.
- كبسولة الرئيسية أعلى البداية، عنوان Cairo Bold 36sp، وصف سطران، شرائح لنوع العمل والسنة والتقييم المتاحين. لا توجد بيانات العمر أو الأنواع أو HDR في Film؛ لا ننشئ قيمًا وهمية.
- أزرار 48dp وتكبير 1.07؛ تشغيل الأفلام واستكشاف حلقات المسلسل، قائمة مفضلة وتفاصيل.
- مؤشرات تعرض نافذة سبعة أعمال حول العمل المحدد؛ تحديد بطاقة يغير العمل والخلفية، ولا توجد دورة آلية تغيّر الأزرار أثناء التركيز.
- جميع صفوف الرئيسية أفقية 16:9 مع صور backdrop، حواف 10dp، تكبير 1.12 وإطار 2dp. البطاقات العمودية في الأقسام الأخرى تبقى كما هي.
- إعادة استخدام TvShelfRow تحت ContentRailRow يحتفظ بالتقدم، التمرير المركزي واستعادة التركيز بعد التفاصيل. تتجه أزرار العرض إلى آخر بطاقة بالصف الأول، وتتجه بطاقات هذا الصف إلى التشغيل.
- النماذج الفعلية Film/Shelf والدوال open/play/toggle، وليست MediaItem/Category وopenDetails/toggleWatchlist المذكورة في وصف الطلب. تبقى وظائف المصدر دون تغيير.
- فحص مرئي على تلفزيون فعلي غير منفذ.
