# Cinema IQ 3.4 — بداية الرئيسية صفحة الأعمال الشائعة

- أول ما تفتح الرئيسية: صفحة كاملة للأعمال الشائعة (الأعلى تقييمًا والأحدث بالتناوب) بخلفية العمل بكامل الشاشة وتحتها التفاصيل: العنوان، النوع، التقييم، السنة، المدة، الوصف، الترجمة، وزر «افتح الفيلم/المسلسل».
- يتغير العمل تلقائيًا كل 8 ثوانٍ، ويتغير يدويًا بزري يمين ويسار (اليسار = التالي، اليمين = السابق). أي تغيير يدوي يعيد حساب مهلة التغيير التلقائي. عند أول عمل يخرج زر اليمين إلى القائمة الجانبية.
- زر OK يفتح صفحة العمل. لا أزرار أخرى في هذه الصفحة حتى لا يتعارض التنقل بين الأزرار مع تغيير العمل.
- زر الأسفل ينقل إلى باقي الأقسام: «تابع المشاهدة» أولًا (إن وُجدت) ثم بقية الأقسام. تستقر كل صف قرب أعلى الشاشة، والصعود من الصف الأول يعود إلى صفحة الأعمال الشائعة.
- الخلفية تتلاشى عند النزول إلى الأقسام، وتُحمَّل الصورتان المجاورتان مسبقًا.
- لم يُبنَ المشروع ولم يُشغَّل.
