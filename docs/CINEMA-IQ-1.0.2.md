# سينما آي كيو 1.0.2

تغييرات تصميم بطلب صريح من المستخدم (قاعدة AGENTS.md تسمح بتغيير التصميم عند الطلب). لم يُبنَ أي APK؛ البناء يحتاج موافقة جديدة.

- **أيقونات المشغّل**: مجموعة متجهة واحدة (`PlayerTransportIcon.kt`) بنفس الصندوق 28dp ونفس سماكة الخط وأطراف مستديرة: تشغيل، إيقاف، ±10، الحلقات، الترجمة، الجودة (منزلقات)، التالية، إغلاق. كل الأزرار دائرة 60dp (التشغيل 72dp) على خط وسط واحد؛ اسم الزر يظهر تحت الزر المركّز فقط كطبقة لا تزيح الصف.
- **التقييم**: يُقرأ من stars/rate/imdbRate/imdb_rate/imdbRating/rating/tmdbRate (أول قيمة موجبة)، يُحوَّل إلى 0–10 بخانة عشرية، ويظهر في صفحة التفاصيل بنجمة ذهبية في أول سطر البيانات. يختفي إن لم يرسل المصدر تقييمًا.
- **المشاركة**: حُذف الزر.
- **معاينة التريلر**: عند بقاء التركيز على كارت في أي صف 3 ثوانٍ يتوسع بحركة سلسة (البوستر يصير 16:9 بنفس الارتفاع، والبطاقة الأفقية 1.5×) ويشتغل التريلر صامتًا فوق الصورة بظهور تدريجي، مع العنوان والتقييم. الانتقال إلى كارت آخر يعيده لحجمه ويوقف التريلر. لا يعمل في الشبكات (أفلام/مسلسلات/قائمتي/بحث) ولا في صف الحلقات.
  - المصدر: رابط تريلر من بيانات الخدمة إن وُجد (trailer/youtube/…)، وإلا بحث على يوتيوب بالعنوان الإنجليزي (en_title) أو العربي + السنة + official trailer، وأول فيديو يُعتمد. هذا استخراج من صفحة نتائج عامة وقد يتعطل إذا غيّرها يوتيوب، وقد لا تطابق النتيجة العمل دائمًا. البديل الأدق مفتاح YouTube Data API.
  - التشغيل عبر WebView بمشغّل YouTube IFrame. الفيديوهات التي يمنع صاحبها تضمينها تُهمل ويبقى الكارت بالصورة.
  - الثوابت `TrailerDwellMillis` و`TrailerMuted` في `TrailerPreview.kt`.
- الإصدار 1.0.2، versionCode 12.

## مفتاح YouTube Data API
1. في Google Cloud Console فعّل YouTube Data API v3 وأنشئ API key (قيّده على هذه الواجهة فقط).
2. أضف في `local.properties` (ملف غير مرفوع إلى git): `youtube.api.key=AIza...` ثم أعد البناء. بديلًا: متغير البيئة `YOUTUBE_API_KEY`.
3. التطبيق يستخدم المفتاح للبحث عن فيديوهات قابلة للتضمين فقط (`videoEmbeddable=true`). عند غيابه أو رفض الخدمة (حصة 10,000 وحدة/يوم = 100 بحث) يعود تلقائيًا إلى البحث بقراءة صفحة النتائج.
4. نتيجة كل عمل تُحفظ على الجهاز بعد أول نجاح، فلا يتكرر البحث ولا تُستهلك الحصة.
المفتاح يُضمَّن في APK، فلا تستخدم مفتاحًا ذا صلاحيات أو فوترة مفتوحة.

## إصلاح عدم ظهور التريلر
- المشغّل صار يفتح صفحة `https://www.youtube.com/embed/<id>` مباشرة مع ترويسة Referer (التضمين عبر loadData بلا Referer يُرفض غالبًا بخطأ 153)، ثم يفحص عنصر `<video>` كل نصف ثانية ولا يُظهره إلا عند تقدّم التشغيل فعلًا، ويستسلم بعد ~15 ثانية.
- الـWebView صار بشفافية كاملة تحت الصورة والصورة تتلاشى فوقه (WebView بشفافية 0 قد لا يبدأ التشغيل).
- للتشخيص: سجلات logcat بالوسم `Trailer` (playing / no playback / load error).

## تشخيص التريلر
`TrailerDebug = true` في `TrailerPreview.kt` يعرض شريطًا أصفر صغيرًا أعلى الكارت الموسّع بإصدار WebView وحالة عنصر الفيديو وعنوان الصفحة ونص خطأ يوتيوب إن وُجد. عند الفشل يبقى الكارت مفتوحًا 10 ثوانٍ لقراءته. اجعله false بعد حل المشكلة.

## خطأ 152 (التضمين محظور)
- الفيديو الذي يمنع صاحبه تضمينه يُعرض في يوتيوب بالخطأ «152 - 4». النسخة الحالية تتحقق قبل الاختيار عبر oEmbed العام (يردّ 401 للمحظور) وتفضّل الفيديوهات المعنونة trailer/teaser/official/تريلر/إعلان، ثم تجرب المرشح التالي تلقائيًا عند فشل أحدها.
- ترويسة Referer مبنية على اسم الحزمة (`https://com.cinemaplus.rebuilt`) بدل youtube.com.
- المعرّف الذي نجح يُحفظ على الجهاز ويُبدأ به في الجلسات التالية.

## صوت التريلر وتريلر صفحة التفاصيل
- الإعدادات ← التشغيل ← «صوت التريلر» (مكتوم/مفتوح). يُحفظ على الجهاز، ويطبَّق على معاينات الكروت (الافتراضي مكتوم). يُقرأ عبر `LocalTrailerMuted`.
- صفحة الفيلم/المسلسل: زر «التريلر» بجانب «إضافة إلى قائمتي» يفتح التريلر بملء الشاشة ويشتغل بصوت دائمًا لأنه طلب صريح. زر الرجوع يغلقه، وبقية أزرار الريموت معطّلة أثناء العرض. عند رفض فيديو للتضمين يجرّب التالي، وإن فشلت كلها تظهر رسالة.
- شريط التشخيص الأصفر أُوقف (`TrailerDebug = false`).

## الأفلام والمسلسلات حسب التصنيف
- صفحتا «أفلام» و«مسلسلات» صارتا صفوفًا أفقية، صف لكل تصنيف (حتى 12)، بدل الشبكة الواحدة. قائمة التصنيفات من `CinemanaApi.categories()` ← المسار `categories`، وأعمال كل تصنيف من نفس مسار الكتالوج بعد وضع رقم التصنيف في `categoryNb` (كان 0 دائمًا).
- المسار `categories` وأسماء حقوله (nb/ar_title/en_title…) لم يُتحقق منهما حيًا في بيئة العمل. إن فشل الطلب أو رجعت القائمة فارغة تعود الصفحة تلقائيًا إلى الشبكة المسطحة السابقة، فلا تنكسر.
- تصنيف يفشل طلبه أو يرجع فارغًا يُتجاهل وحده.
- العرض التجريبي وقائمتي والبحث بلا تغيير.
