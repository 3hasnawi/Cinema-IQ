# Cinema IQ 3.7 (versionCode 39)

## جلب صور ووصف من TMDB بدل بيانات المصدر الضعيفة
- ملف جديد `data/TmdbMetadata.kt`: يبحث في themoviedb.org بالاسم (الإنجليزي أولا ثم العربي) والسنة، ويقبل النتيجة فقط
  إذا تطابق الاسم وكانت السنة ضمن ±1، وإلا تبقى بيانات المصدر (لا يُعرض عمل خاطئ أبدا).
- يستبدل: خلفية الهيرو (w1280) والبوستر (w780). ويملأ الوصف والتقييم فقط عند غيابهما من المصدر.
- النتائج (حتى حالة عدم وجود مطابقة) تُخزَّن على القرص: 30 يوما للموجود و3 أيام للمفقود.
- الصفحة الرئيسية تطلب بيانات الأعمال المميزة تلقائيا، وصفحة التفاصيل تطلب العمل المفتوح.
- بدون مفتاح لا يحدث أي طلب ويستمر التطبيق بصور المصدر.

## الإعداد
أضف في `local.properties`:
```
tmdb.api.key=مفتاحك_v3
```
أو متغير البيئة `TMDB_API_KEY`. المفتاح من حسابك في themoviedb.org (Settings → API).

## الترخيص
الاستخدام المجاني لغير التجاري مع الإسناد. عند وجود مفتاح تعرض الإعدادات عبارة:
"This product uses the TMDB API but is not endorsed or certified by TMDB." أما الاستخدام التجاري فيتطلب مراسلة TMDB.

لم يُبنَ المشروع ولم يُشغَّل.
