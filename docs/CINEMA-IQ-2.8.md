# Cinema IQ 2.8 — صفحة التفاصيل: بوستر ثابت ولوحة سفلية

سبب المشكلة في 2.7: الصفحة كانت قائمة تتمرر، فكان موضع التمرير يُظهر الحلقات والأعمال المشابهة مباشرة.

## الحل
- الصفحة الآن بوستر ثابت بملء الشاشة؛ لا قائمة تتمرر فيه.
- أسفل اليمين: العنوان وأزرار «شاهد الآن/استئناف» و«قائمتي» و«التريلر»؛ والتفاصيل عائمة أمامها بلا إطار.
- زر الأسفل في الريموت يفتح لوحة سفلية فيها المواسم والحلقات (للمسلسل) و«أعمال مشابهة»، والخلفية تُعتَّم خلفها.
- زر الأعلى (من الصف الأعلى) أو الرجوع يغلق اللوحة ويعيد التركيز لزر التشغيل.
- البطاقات أصغر: الحلقات بعرض 210 والأعمال المشابهة بعرض 116، دون معاينة تريلر فيها.
- لم يُبنَ المشروع ولم يُشغَّل.
