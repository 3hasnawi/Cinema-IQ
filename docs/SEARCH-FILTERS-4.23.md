# Search, filters and phone player (batch 3)

- **Search history**: the last 8 successful searches show as chips while the box is empty (TV and phone), with a clear button.
- **Filter and sort**: "النوع" (all / movies / series) and "الترتيب" (default / rating / newest / name) on search results and on "قائمتي". Each press cycles to the next value. Explore is not filtered.
- **Phone player**: double-tap the left/right half to seek 10 s; a floating-window (picture-in-picture, Android 8+) button was added to the controls.
- Brightness/volume swipe gestures were not added.

Not compiled locally; the CI check on the PR is the first real compile. No APK is built.
