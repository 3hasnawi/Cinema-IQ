# Cinema IQ 2.7 — ضبط صفحة التفاصيل

- أول شاشة في الصفحة بوستر كامل (حجم الشاشة بالضبط)، ولا يظهر شيء آخر قبل النزول.
- أسفل اليمين: العنوان، ثم أزرار «شاهد الآن / استئناف»، «قائمتي»، «التريلر».
- التفاصيل (التقييم، السنة، المدة، الوصف، الترجمة) عائمة أمام الأزرار فوق البوستر بلا إطار.
- «أعمال مشابهة» (وللمسلسل المواسم والحلقات) لا تظهر إلا عند النزول للأسفل.
- أُزيل شريط الحقائق وزر الانتقال لأنهما صارا مكررين.
- لم يُبنَ المشروع ولم يُشغَّل.
