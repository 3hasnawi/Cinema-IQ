# Cinema IQ 3.3 — بوستر التفاصيل بكامل الشاشة

في 2.9 صارت الصور غير العريضة (البوستر العمودي) تُعرض صغيرة في الوسط (66% من الارتفاع). التعديل:
- البوستر العمودي يُعرض كاملًا بارتفاع الشاشة كله ومتوسطًا، بلا قص ولا تمطيط.
- جانباه يمتلئان بنسخة مكبَّرة خافتة (شفافية 30%) من الصورة نفسها؛ الطلب مشترك فلا يُفك ترميز الصورة مرتين.
- الصور العريضة (16:9 تقريبًا) كما كانت: تملأ الشاشة.
- يسري أيضًا على هيرو الرئيسية.
- لم يُبنَ المشروع ولم يُشغَّل.
